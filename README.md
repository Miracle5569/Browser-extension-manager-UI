## О проекте 📝

Этот проект — **учебный макет от [Frontend Mentor](https://www.frontendmentor.io)**. Целью была отработка навыков верстки и JavaScript. Макет будет сверстан для десктопной и мобильной версий.

- **Задача:** Реализовать макет с сопутствующим для него функционалом.
- **Моя роль:** Frontend-разработчик (верстка, логика на JS).
